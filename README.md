# JECHO: Scalable Echo Chamber Detection via Jaccard-based Homophily and Seed Expansion

Implementation for the main experiments and ablation studies. The workflow is a
dataset-preparation stage followed by experiment scripts that share a common
execution framework (`General_Runner.py`).

---

## Requirements

- Python >= 3.11
- numpy == 2.2.6
- scipy == 1.17.0
- scikit-learn == 1.8.0
- networkx == 3.5
- python-igraph == 0.11.4
- leidenalg == 0.11.0
- matplotlib == 3.10.0
- heapdict == 1.0.1
- tqdm == 4.67.1

Install with:

```bash
pip install numpy==2.2.6 scipy==1.17.0 scikit-learn==1.8.0 networkx==3.5 \
    python-igraph==0.11.4 leidenalg==0.11.0 matplotlib==3.10.0 heapdict==1.0.1 tqdm==4.67.1
```

The code is CPU-only; no GPU is required. The SBM generation call auto-adapts to
either igraph signature (`Graph.SBM(n, ...)` or `Graph.SBM(pref_matrix, ...)`), so
it also works on other igraph versions.

---

## Datasets

Datasets live under `EchoChambersDatasets/` (configurable via `pre_path`).

- **SBM (synthetic):** generated by the code, no external files needed.
- **Real-world (Facebook, Twitter, Git, LastFM, Pokec):** not shipped. Download
  the edge lists from the SNAP repository and place each as `{name}_edges.txt`
  (one `source target` pair per line) before running.
- **Reddit-RW:** provided as `EchoChambersDatasets/RW_Reddit_edges.zip` (unzip
  before use).

Opinion values for real-world graphs are generated by the setup step; for
Twitter-RW / Reddit-RW they come with the data and are rescaled to [-1, 1].

## How to run

Run from the repository root. Each script has a `datasets = [...]` line near the
bottom that selects what runs — edit it to choose datasets and sizes. Result
pickles are written to the `pre_path_results` folder set inside each script.

To quickly verify the environment (generates a small SBM and runs every method -
all JECHO score/expansion combinations plus the SEDA, EchoGAE, and Q-Peeling
baselines - in well under a minute), run:

```bash
python full_test.py
```

It prints PASS/FAIL per method. This is a code-path check, not a correctness
benchmark: on such a small graph some variants may legitimately find no chamber.

### 1. Dataset setup

```bash
python 1-dataset_setup.py
```

Generates SBM graphs and/or assigns opinions to real-world graphs, saving the
processed datasets (`*_edges.txt` and `*_{fj,filtering,extremes}.pkl`).

### 2. Main experiment (Table 1)

```bash
python 2-run_main_experiment.py
```

Runs JECHO, SEDA, and EchoGAE over the selected datasets, opinion variants
(`_fj`, `_filtering`, `_extremes`), and 10 seeds. The Q-Peeling baseline is run
separately:

```bash
python QPeeling.py
```

### 3. Ablation studies

- `3-run_ABL_seed_ratio_experiment.py`, `3-2-...` — seed-scoring ablation
  (structural isolation vs. seed ratio for different seed-scoring functions).
- `4-run_ABL_seed_ratio_expansion_experiment.py`, `4-2-...` — seed-expansion
  ablation (SSE vs. AttriPPR).
- `5-run_ABLmodularity_experiment.py` — modularity case study (Figure 4): sweeps
  SBM target modularity and runs all methods per level. Note the
  `modularity_values = [...][6:]` slice runs only the last levels; remove `[6:]`
  to sweep the full 0.1-0.9 range.

## Module overview

- `JECHO.py` — JECHO algorithm: JHO seed scoring and score-based seed expansion (SSE).
- `partition_based_opinion_assignment.py` — SBM generation and opinion assignment
  (partition sampling, Friedkin-Johnsen, filtering/extreme variants).
- `General_Runner.py` — shared execution framework used by the experiment scripts.
- `SEDA.py`, `EchoGAE.py`, `QPeeling.py` — baseline methods.
- `AttriPPR.py`, `CustomizedPageRank.py` — attribute-aware personalized PageRank
  (AttriPPR expansion baseline).
- `SeedSelectionModels.py` — alternative seed-scoring functions used in ablations.
- `FJ_Laplacian_large_graphs.py` — Friedkin-Johnsen solver for large graphs.
- `utils.py` — graph I/O and structural-isolation / homogeneity metrics.
- `dataset_generation_SBM.py` — SBM helpers.

## Reproducibility

Random seeds are set in the code (`seed_id = 42` in the runners; per-test seeds
derived from it). The experiment scripts emit result pickles only; the tables and
figures are produced from those pickles by a separate plotting/aggregation step.
The singleton lower-bound baseline (Section 5.2) is likewise applied when
assembling the final table — see `singleton_baseline` in `utils.py`.

Runtime scales with graph size: small graphs finish in seconds; Pokec (1.6M
nodes) takes on the order of hours for JECHO, and the slower baselines dominate
total time. A full reproduction across all datasets, 10 seeds, and all methods is
a multi-day job.
